Calculadora Interativa em Java (Swing)

Uma aplicação desktop simples e intuitiva de calculadora, desenvolvida em **Java**, que utiliza janelas interativas da biblioteca **Swing** (`JOptionPane`) para entrada e exibição de dados.

O projeto foi construído para demonstrar conceitos fundamentais da linguagem Java, tratamento de dados e interfaces gráficas básicas.

---

 Funcionalidades

- **Operações Matemáticas Básicas:** Adição (`+`), Subtração (`-`), Multiplicação (`x`) e Divisão (`/`).
- **Interface Gráfica Amigável:** Interação via janelas pop-up (diálogos interativos).
- **Validação de Divisão por Zero:** Tratamento do erro de divisão por zero para evitar falhas de execução.

---

 Tecnologias Utilizadas

- **Linguagem:** Java (JDK 8 ou superior)
- **Interface Gráfica:** Java Swing (`JOptionPane`)
